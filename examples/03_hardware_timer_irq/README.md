# ⏱️ Example 3: Hardware Timer Interrupts (IRQ0)

Практический пример настройки и обработки аппаратных прерываний (Hardware IRQ) и таймера для процессора **LIM M2**.

---

## 📌 Что демонстрирует этот пример:
1. **Таблица векторов прерываний (IVT):**
   - Настройка 32-битного вектора прерывания `$ir0` на адрес подпрограммы обработки `timer_isr` (`0x00000080`) с помощью команды `MSP.ld $ir0, timer_isr`.
2. **Глобальное разрешение прерываний (`MIE`):**
   - Установка бита 9 (`MIE`) в регистре флагов `FREG` через побитовое ИЛИ: `MSP.or $freg, 0x0200`.
3. **Настройка контроллера аппаратного таймера (MMIO):**
   - Таймер расположен по адресу `0x00030010`.
   - Запись интервала перезагрузки (`Reload Value = 25` циклов шины) в регистр `0x00030010`.
   - Включение таймера (`Control = 1`) в регистр `0x00030012`.
4. **Фоновые вычисления:**
   - В основном цикле процессор непрерывно рассчитывает ряд чисел Фибоначчи в регистрах `R1`, `R2`, `R3`.
5. **Аппаратный обработчик прерывания (ISR):**
   - При срабатывании таймера процессор аппаратно сохраняет 32-битный `PC` и 16-битный `FREG` на стек `SREG`, выставляет статус `FREG.INTR = 1` и переходит в `timer_isr`.
   - Обработчик инкрементирует счетчик тиков в оперативной памяти (`0x00000200`), дописывает символ `*` на экран и сбрасывает флаг готовности таймера.
   - Команда `RET` снимает со стека сохраненные флаги и `PC`, автоматически очищая флаг `INTR` и возвращая управление точно в точку прерванных вычислений.

---

## 🛠️ Файлы примера:
* **`timer_irq.asm`** — Исходный код с обработчиком прерывания.
* **`timer_irq.bin`** — Бинарный файл (155 байт).
* **`timer_irq.hex`** — Шестнадцатеричный образ для симулятора.

---

## ⚡ Компиляция и запуск:

```bash
# Компиляция:
python3 compiler/compiler.py examples/03_hardware_timer_irq/timer_irq.asm -l

# Запуск в интерактивном симуляторе:
python3 sim/LIM2.py examples/03_hardware_timer_irq/timer_irq.hex -i
```
