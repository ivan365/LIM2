# 🖥️ Example 2: Modular Text Terminal & Hex Formatter

Пример модульного текстового вывода и форматирования чисел для процессора **LIM M2**.

---

## 📌 Что демонстрирует этот пример:
1. **Подпрограммы и конвенция вызовов (`CALL` / `RET`):**
   - Вызовы процедур с автоматическим сохранением 32-битного счетчика команд `PC` и 16-битного регистра флагов `FREG` в аппаратный стек `SREG` (`SP`).
2. **Прямое потоковое отображение в видеопамять TextScreen (`0x00010000`):**
   - Быстрый вывод символов через указатель `PTREG` с включенным аппаратным автоинкрементом (`FREG.AIP = 1`).
3. **Шестнадцатеричный конвертер (`print_hex16`):**
   - Принимает 16-битное число в `$0` и преобразует его в 4 символа ASCII (`'0'..'9'`, `'A'..'F'`).
   - Использует логические сдвиги вправо (`BSR`), битовую маску (`AND`) и аппаратный компаратор (`CMP`, `JCR >=`).
4. **Результат на экране:**
   Выводит форматированную строку:
   ```text
   LIM2 TERM: R1=0xCAFE R2=0x015E
   ```

---

## 🛠️ Файлы примера:
* **`terminal_demo.asm`** — Исходный код на ассемблере.
* **`terminal_demo.bin`** — Бинарный файл (217 байт).
* **`terminal_demo.hex`** — Шестнадцатеричный образ для симулятора.

---

## ⚡ Компиляция и запуск:

```bash
# Компиляция:
python3 compiler/compiler.py examples/02_text_terminal_io/terminal_demo.asm -l

# Запуск в интерактивном TUI:
python3 sim/LIM2.py examples/02_text_terminal_io/terminal_demo.hex -i
```
