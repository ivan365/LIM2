# 🧮 Example 4: 3-Operand ALU, Flags & Logic

Демонстрация работы трехоперандного АЛУ, побитовой логики, сдвигов и флагов процессора **LIM M2**.

---

## 📌 Что демонстрирует этот пример:
1. **Трехоперандные регистровые команды АЛУ (`Rd = Rs1 op Rs2`):**
   - Сложение: `ADD $3, $1, $2` ($30 + 12 = 42$)
   - Вычитание: `SUB $4, $1, $2` ($30 - 12 = 18$)
   - Умножение: `MUL $5, $1, $2` ($30 \times 12 = 360$)
   - Целочисленное деление: `DIV $6, $1, $2` ($30 / 12 = 2$)
   - Остаток от деления: `MOD $7, $1, $2` ($30 \pmod{12} = 6$)
2. **Арифметическое переполнение и флаг переноса (`CF`):**
   - Сложение $0xFFFF + 0x0002 = 0x10001 \to$ в регистре остается $0x0001$, а флаг переноса `CF` поднимается в `1`.
3. **Побитовые логические инструкции и сдвиги:**
   - Побитовое И: `AND $3, $1, $2` ($0xAA55 \ \& \ 0x00FF = 0x0055$)
   - Побитовое ИЛИ: `OR $4, $1, $2` ($0xAA55 \mid 0x00FF = 0xAAFF$)
   - Исключающее ИЛИ: `XOR $5, $1, $2` ($0xAA55 \oplus 0x00FF = 0xAAAA$)
   - Сдвиги: `BSL $6, 4` ($1 \ll 4 = 16$), `BSR $6, 2` ($16 \gg 2 = 4$).
4. **Аппаратный компаратор и условные переходы:**
   - Сравнение через `CMP $1, $2` и проверка через `JCR !=, error_target`.
5. **Вывод на экран:**
   - При успешном прохождении всех тестов пишет на экран `TextScreen` (`0x00010000`): `"ALU OK"`.

---

## 🛠️ Файлы примера:
* **`math_demo.asm`** — Исходный код тестов АЛУ.
* **`math_demo.bin`** — Бинарный файл (160 байт).
* **`math_demo.hex`** — Шестнадцатеричный образ для симулятора.
