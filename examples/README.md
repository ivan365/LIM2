# 📚 Каталог практических примеров LIM M2 (Examples)

В этом каталоге собраны эталонные, полностью протестированные и готовые к запуску примеры программ на языке ассемблера для архитектуры процессора **LIM M2**.

Каждый пример содержит исходный ассемблерный файл (`.asm`), скомпилированные образы (`.bin`, `.hex`) и персональное руководство (`README.md`).

---

## 🗂️ Список доступных примеров:

| Пример | Директория | Описание ключевых возможностей |
| :--- | :--- | :--- |
| **01. Первичный загрузчик** | [**`01_bootloader/`**](01_bootloader/) | Инициализация стека `SP` и флагов `FREG`, вывод баннера в видеопамять TextScreen (`0x00010000`), релокация ядра из ROM в RAM (`0x00008000`), проверка magic-сигнатуры `0x4C49` и 32-битный прыжок (`JMP 0x00008002`). |
| **02. Текстовый терминал и HEX-вывод** | [**`02_text_terminal_io/`**](02_text_terminal_io/) | Модульные подпрограммы (`CALL` / `RET`), форматирование 16-битных чисел в шестнадцатеричные символы ASCII (`0xCAFE`), сдвиги (`BSR`), маскирование (`AND`) и вывод на экран через `PTREG` (`AIP=1`). |
| **03. Аппаратный таймер и прерывания** | [**`03_hardware_timer_irq/`**](03_hardware_timer_irq/) | Настройка таблицы векторов IVT (`$ir0`), глобальное разрешение прерываний (`MIE`), конфигурирование таймера MMIO (`0x00030010`), фоновый расчет чисел Фибоначчи и обработчик ISR с автоматическим возвратом `RET`. |
| **04. АЛУ, побитовая логика и компаратор** | [**`04_alu_chaining_and_math/`**](04_alu_chaining_and_math/) | 3-операндные команды АЛУ (`ADD`, `SUB`, `MUL`, `DIV`, `MOD`), фиксация флага переноса `CF`, побитовые операции (`AND`, `OR`, `XOR`), логические сдвиги (`BSL`, `BSR`) и условные переходы `JCR`. |

---

## ⚡ Быстрая компиляция всех примеров

Вы можете перекомпилировать все примеры одной командой:

```bash
# Из корня репозитория LIM2:
python3 compiler/compiler.py examples/01_bootloader/bootloader.asm
python3 compiler/compiler.py examples/02_text_terminal_io/terminal_demo.asm
python3 compiler/compiler.py examples/03_hardware_timer_irq/timer_irq.asm
python3 compiler/compiler.py examples/04_alu_chaining_and_math/math_demo.asm
```

## 🖥️ Запуск любого примера в симуляторе

### 1. Графический оконный режим (GUI):
```bash
python3 sim/gui.py
# В меню симулятора выберите нужный .hex файл из папки examples/
```

### 2. Интерактивный консольный терминал (TUI):
```bash
python3 sim/LIM2.py examples/01_bootloader/bootloader.hex -i
```
