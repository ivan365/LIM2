# 🚀 Example 1: Stage-1 Direct Memory Bootloader

Полноценный пример прямого первичного загрузчика (Stage-1 Bootloader) для микропроцессора **LIM M2**.

---

## 📌 Что демонстрирует этот пример:
1. **Инициализация системы:**
   - Настройка указателя стека `SP` (`SREG`) в оперативную память (`MSP.ld $sp, 0x00007F00`).
   - Настройка флагового регистра `FREG`: переход в режим Супервизора (`PRV=1`, бит 11) и включение аппаратного автоинкремента адреса `PTREG` (`AIP=1`, бит 12).
2. **Прямой вывод в видеопамять (VRAM):**
   - Запись приветственной строки на экран `TextScreen` (`0x00010000`) с помощью автоинкремента `PTREG` (`LRM.b 0xXX, [$ptreg]`).
3. **Релокация полезной нагрузки (Kernel Payload):**
   - Перенос образа прошивки / ядра из ROM-памяти по адресу `0x00000100` в RAM по адресу `0x00008000`.
4. **Валидация сигнатуры (Magic Word):**
   - Проверка первых 2 байтов заголовка ядра `0x4C49` (ASCII `"LI"`). При несовпадении загрузчик выводит `"ERR"` и останавливается.
5. **Передача управления ядру:**
   - Безусловный 32-битный прыжок на точку входа загруженного ядра в ОЗУ: `JMP 0x00008002`.

---

## 🛠️ Файлы примера:
* **`bootloader.asm`** — Исходный код загрузчика и встроенного ядра.
* **`bootloader.bin`** — Скомпилированный бинарный образ (301 байт).
* **`bootloader.hex`** — Шестнадцатеричный дамп с комментариями адресов.

---

## ⚡ Компиляция и запуск:

### 1. Компиляция:
```bash
# Из корня репозитория LIM2:
python3 compiler/compiler.py examples/01_bootloader/bootloader.asm -l
```

### 2. Запуск в симуляторе (GUI):
```bash
python3 sim/gui.py
# В окне симулятора нажмите "Загрузить HEX" и выберите examples/01_bootloader/bootloader.hex
```

### 3. Запуск в интерактивном терминальном отладчике (TUI):
```bash
python3 sim/LIM2.py examples/01_bootloader/bootloader.hex -i
```
